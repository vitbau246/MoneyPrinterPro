MoneyPrinterPro (ban portable)
Nguon ma goc: https://github.com/harry0703/MoneyPrinterTurbo
(Ban nay khong ket noi kho goc: khong tu cap nhat ma nguon.)

1, start.bat         mo WebUI (+ bot Telegram neu da cau hinh bot_token)
2, telegram_bot.bat  chi mo bot Telegram
3, api.bat           mo API (http://127.0.0.1:8080/docs)
4, update.bat        cai lai thu vien Python

Lan dau chay, thu vien Python duoc tu cai va config.toml duoc tu tao.
Cac file .bat o day chi goi file cung ten trong thu muc ma nguon va duoc tu cap nhat.
